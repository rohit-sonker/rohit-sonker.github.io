# rohit-sonker.github.io

Personal website of Rohit Sonker. Plain HTML and CSS, served by GitHub Pages (no build step).

- `index.html`: home page (about, news, publications, experience)
- `cv/index.html`: CV page; the PDF is `files/RohitSonker_CV.pdf`
- `style.css`, `main.js`: shared styles, dark mode toggle, and nav highlighting
- `about/`, `publications/`, `resume/`, `talks/`, `teaching/`, `portfolio/`: redirects from the old site's URLs

Preview locally:

    python3 -m http.server 8765

Then open http://localhost:8765.
